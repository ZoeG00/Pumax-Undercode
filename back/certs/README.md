# Certificados de ARCA (ex-AFIP)

Coloca en este directorio los archivos generados con OpenSSL y descargados de ARCA:

- `arca.key`: Clave privada generada localmente (RSA 2048)
- `arca.crt`: Certificado digital obtenido desde la web de ARCA / AFIP

Estos archivos están excluidos del control de versiones (.gitignore) por seguridad.
